Medidas de reducción del riesgo por líneas de acción, temporalidad y escala de aplicación

Panel de medidas · líneas de acción × temporalidad

Cada celda indica cuántas medidas hay para esa línea de acción y plazo. El color crece con la cantidad. Toque una celda, una fila o un encabezado de columna para ver esas medidas abajo.

Cómo leer este panel
  • Línea de acción (filas): el tipo de medida (institucional, silvicultura, rondas hídricas, participación comunitaria, etc.).
  • Temporalidad (columnas): corto, mediano o largo plazo según el horizonte de implementación.
  • Escala: nivel territorial donde aplica la medida (departamental, municipal, local, regional o multiescala). Use los filtros para acotar.
  • Toque una celda para ver las medidas de esa línea y plazo; una fila para toda la línea; una columna para todo el plazo. «Ver todas» quita la selección.
